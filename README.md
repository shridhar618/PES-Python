# Python Programming Coursework

Python coursework and assignments from my university program, from core language features through data handling, pandas, async programming, web scraping and databases.

## Contents

| Unit | Topics |
|---|---|
| `unit-1/` | Functions, lambdas, comprehensions, recursion, iterators, decorators, `collections` (`Counter`, `OrderedDict`), standard library |
| `unit-2/` | Object-oriented programming: constructors and destructors, encapsulation, inheritance (including multilevel), polymorphism, overloading and overriding, abstraction, composition, introspection, metaclasses |
| `unit-3/` | File handling (text, CSV, JSON, XML, Excel, pickle), exception handling, pandas DataFrames, sensor-data assignments |
| `unit-4/` | `asyncio`, process forking, HTTP requests, static and dynamic web scraping, data streaming, PostgreSQL and SQLAlchemy |
| `ESA/` | Exam practice |

The root folder holds the sample datasets (CSV, JSON, XML, XLSX, pickle) used by the exercises.

## Running

```bash
pip install pandas openpyxl requests sqlalchemy
python3 unit-2/inheritence.py
```
